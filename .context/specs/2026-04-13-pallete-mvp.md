# Спецификация: Pallete — кроссплатформенный сборщик палитр

## Контекст

Лёгкое (<15MB), быстрое (<500мс старт, <100MB RAM) десктоп-приложение для macOS/Windows/Linux, которое собирает палитры из произвольного вставленного текста (ASCII-таблицы, Markdown, CSS/SCSS-переменные, списки hex). Решает проблему неинтуитивности Pikka (невозможно нормально редактировать/удалять палитры). Работает полностью офлайн, без телеметрии.

## Требования

### Функциональные (MVP)

- **Иерархия**: Проект → Палитры → Цвета. Палитра принадлежит одному проекту.
- **Импорт через вставку**: парсер распознаёт ASCII-таблицы, Markdown-таблицы, CSS/SCSS-переменные, голые списки hex. Правило группировки: 1 строка таблицы = 1 палитра (имя из первой колонки).
- **Способы ввода**: модалка «Импорт» с preview, глобальный Cmd+V (с undo-toast), drag-and-drop файлов (.txt/.md/.css).
- **Preview-диалог импорта**: авто-детект header-строки (нет hex → заголовок) + чекбоксы «первая строка = header», «первая колонка = имена палитр» для переопределения. Отображает разобранные палитры/цвета до подтверждения.
- **Дубликаты при импорте**: диалог merge / replace / skip.
- **Модель цвета**: hex + имя (из парсера) + роль/токен (primary/accent/bg) + alpha.
- **CRUD палитр/цветов**: переименование (F2), удаление (Delete/Backspace на выделенном + иконка корзины при hover), дубликат.
- **Копирование**: клик по свотчу → hex в буфер (формат настраивается: hex/rgb/hsl).
- **Undo/redo**: Cmd+Z / Cmd+Shift+Z на ВСЕ операции (создание, удаление, редакт).
- **Темы**: light / dark / follow system. Нейтральная палитра UI чтобы не мешать восприятию цветов.

### Вне MVP (следующие итерации)

- Inline-редактирование цветов + DnD-перестановка.
- Экспорт (Copy as CSS/JSON/Tailwind в буфер; Save As для SVG/PNG).
- Генерация вариаций (shades/tints, WCAG-проверка).
- Пипетка с экрана.
- Автообновления (требуют сервера обновлений).

### Нефункциональные

- Бинарник < 15MB, старт < 500мс, RAM < 100MB.
- Offline-only, нулевая телеметрия, нулевые сетевые запросы.
- Кроссплатформенность: macOS, Windows, Linux.
- Первый релиз unsigned (без Apple Developer / Windows code signing) — документировать обход Gatekeeper/SmartScreen.

## Архитектура

**Стек**: Tauri (Rust) + SolidJS + Vite + TypeScript.

**Разделение ответственности**:
- **Rust (tauri commands)**: парсер текста, файловый IO (workspace-индекс, проекты), кодирование/декодирование JSON. Парсер на Rust ради переиспользования в будущем CLI и производительности.
- **Frontend (SolidJS)**: UI, состояние, клавиатурные шорткаты, буфер обмена (через tauri clipboard plugin), undo-stack.

**Хранилище**:
- Один файл на проект: `<user-chosen-dir>/<project-slug>.palette.json` (удобно для Git).
- Workspace-индекс: `~/Library/Application Support/Pallete/workspace.json` (macOS) / XDG-эквивалент на Linux / `%APPDATA%` на Windows. Хранит список путей к проектам + последнее открытое.

**Формат проекта** (JSON):
```json
{
  "version": 1,
  "id": "uuid",
  "name": "Banking",
  "createdAt": "...",
  "updatedAt": "...",
  "palettes": [
    {
      "id": "uuid",
      "name": "CASH",
      "tags": [],
      "colors": [
        { "id": "uuid", "hex": "#66BB6A", "alpha": 1, "name": "изумруд", "role": "primary" }
      ]
    }
  ]
}
```

**Undo-stack**: in-memory command-паттерн (apply/revert), без персистента между сессиями.

## UI/UX

**Layout**: 3 колонки фиксированных пропорций:
1. **Проекты** (20%): список проектов, активный подсвечен. Нижняя панель: «+ New project», «Open folder».
2. **Палитры** (30%): горизонтальные полосы — имя сверху, ряд свотчей снизу. Выделение кликом, Delete удаляет, hover показывает иконку корзины.
3. **Настройка палитры** (50%): имя (редактируемое), список цветов с hex / имя / роль / alpha, действия (копировать, удалить, дубликат).

**Глобальные шорткаты**:
- Cmd+V — импорт из буфера (открывает preview-диалог).
- Cmd+Z / Cmd+Shift+Z — undo/redo.
- Delete/Backspace — удаление выделенного элемента (палитра или цвет в зависимости от фокуса).
- F2 — переименование.

**Preview-диалог импорта**:
- Слева: вставленный текст (редактируемый).
- Справа: разобранные палитры (превью).
- Тоггл: «первая строка — заголовки», «первая колонка — имена палитр», режим группировки (по строкам / всё одной палитрой).

**Тема**: CSS custom properties, auto-detect через `prefers-color-scheme` + manual override в настройках.

## Парсер (Rust)

Алгоритм:
1. Нормализация: strip ASCII-рамок (`│┌┐└┘├┤┬┴┼─`), pipe-разделителей (`|`), markdown-separators (`---`).
2. Токенизация: разбить на строки × ячейки.
3. Детект header-строки: если в строке нет ни одного `#[0-9a-fA-F]{3,8}` → вероятно header.
4. Для каждой ячейки — regex `#[0-9a-fA-F]{3,8}` + extract трейлинг-текст как имя цвета.
5. Группировка: row → palette (имя = первая ячейка без hex) ИЛИ fallback: всё одной палитрой «Imported <timestamp>».
6. Отдельный путь для CSS/SCSS: regex `(?:--|\$)([\w-]+)\s*:\s*(#[0-9a-fA-F]{3,8})` → имя = токен.

## Edge Cases

- Вставка пустого текста → disable кнопку подтверждения в модалке.
- Hex без `#` (например `66BB6A`) → опционально принимать (конфиг парсера).
- RGB-функции `rgb(102,187,106)` → поддержать в v1 (т.к. часто встречается).
- Таблицы с разным числом колонок в строках → допустимо, цвета выстраиваются по порядку.
- Имя палитры-дубликат → merge/replace/skip диалог.
- Очень длинная вставка (1000+ цветов) → не блокировать UI, парсинг через tauri async command.
- Рукописный Cmd+V, когда фокус в textarea модалки импорта → стандартное поведение (не триггерить глобальный импорт).
- Переименование в пустую строку → вернуть предыдущее имя.
- Файл проекта удалён извне → workspace-индекс показывает его как «missing», предлагает remove from workspace.
- Одновременное открытие одного проекта в двух окнах → v1 не поддерживаем (single-instance через Tauri).
- Вставка >1 MB или >10000 цветов → блок подтверждения + warning с цифрами.
- Файл с `version > CURRENT_VERSION` → refuse to open, предложить обновить приложение.

## Риски и митигации

| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| Unsigned build → Gatekeeper/SmartScreen блокируют | Высокая | Документация в README; в будущем — бюджет на подписи |
| Парсер даёт false positives (`#abc` как цвет в не-цветовом контексте) | Средняя | Preview-диалог всегда показывает результат до применения |
| RAM >100MB при больших workspace | Средняя | Lazy-load проектов, один JSON за раз в памяти |
| Конфликты записи при Git-sync (два устройства) | Средняя | JSON human-readable → ручное разрешение; timestamp в updatedAt |
| Tauri webview разный на разных OS (WebKit/WebView2/WebKitGTK) | Средняя | Избегать экзотического CSS, тестировать на всех трёх |
| Clipboard access permissions (Linux/Wayland) | Низкая | Fallback — модалка с textarea |

## Тестовая стратегия

- **Unit-тесты парсера (Rust)**: snapshot-тесты на все форматы (ASCII, MD, CSS, SCSS, голый список, смешанный), edge cases (RGB, `#abc`, hex без `#`, пустой вход, header auto-detect).
- **Unit-тесты store** (frontend): undo/redo, CRUD, дубликаты.
- **Ручное**: UI-флоу, кроссплатформенный smoke-тест сборки.
- E2E (Playwright) — вне MVP.

## Лимиты и защита

- **Hard cap импорта**: 1 MB текста ИЛИ 10000 цветов — что наступит раньше. При превышении: блокировать кнопку подтверждения, показать warning с реальными цифрами. Парсер выполняется как tauri async command.

## Версионирование

См. [ADR 2026-04-13-file-format-versioning](../decisions/2026-04-13-file-format-versioning.md). Стартовая схема v1 включает `palette.tags: string[]` (слот под будущий поиск; UI-редактирование — вне MVP).
